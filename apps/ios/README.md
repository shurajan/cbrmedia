# CBRPlayer (iOS)

SwiftUI-клиент для iPad к [api](../../services/api/README.md). После входа по паролю — главная с плитками разделов:

- **Videos** — медиатека: список видео с фильтром по имени, удаление, HLS-плеер с сохранением позиции;
- **Watchlist** — кого recorder отслеживает и записывает: добавление по имени или ссылке (ответ — после проверки
  recorder'ом, 5–8 с), удаление, включение выключенных, статусы раз в 10 с; у пользователя в эфире — кнопка play,
  живой просмотр прямо с CDN.

Открыть `CBRPlayer.xcodeproj`, схема **CBRPlayer**, симулятор iPad (iOS 26.6+). При первом запуске укажите
`host:port` сервиса (по умолчанию порт `8000`) и пароль, заданный командой `api hash-password`.

## Адрес сервера

api работает по plain HTTP, а iOS (App Transport Security) пропускает его без исключений только на IP-адрес
(`192.168.1.10:8000`), `localhost`, короткое имя без точки (`media:8000`) и имя в зоне `.local` (`media.local:8000`). Полное доменное имя
(`media.example.com:8000`) ATS блокирует — исключений в проекте нет, поэтому указывайте IP или короткое имя.
Вход по IP проверен; блокировка по полному имени — поведение ATS по умолчанию, на устройстве не проверялась.
